# Аудит звука (2026-11-05)

Только анализ, код не менялся. Источник: `assets/sfx/`, `game/core/sfx/`, все вызовы `Sfx.play` / `SfxLoop` / `Footsteps`, разделы M001–M017 и 17 в `GAME_SPEC.md`.

Приоритеты:
- **P1** — нужно для читаемости игры или прямо требуется в `GAME_SPEC.md`; без этого игрок не понимает, что произошло.
- **P2** — заметно улучшает ощущение от игры (обратная связь на частые действия).
- **P3** — полировка.

Задачи в `BACKLOG.md`: P3-081…P3-090 (статус TODO). Новые звуки — записи владельца в `assets/sfx/<группа>/` (как в P3-030); код только подключает группы.

## 1. Что есть сейчас

### Движок звука
- `core/sfx/sfx.gd` — группа = папка `assets/sfx/<группа>/`, случайный дубль без повтора, разброс высоты (×1,12) и громкости (±2 дБ); 3D-плеер на источнике. Всё предзагружается при старте.
- `core/sfx/sfx_loop.gd` — фоновая петля из наложенных дублей (костёр, джунгли, река, ветер).
- `core/sfx/footsteps.gd` — шаги по пройденному пути: земля / трава / река / кусты.
- Одна шина **Master**; в меню паузы один ползунок «Effects volume». Отдельных шин для музыки, эффектов, фона и интерфейса нет.
- **Музыки нет вообще. Звуков интерфейса нет вообще** (все звуки, кроме фоновых петель, — 3D в мире).

### Недочёты в уже подключённых звуках
- **Удар тараном по охотнику беззвучен** (`hunter.gd` `knock`, синтезатор убран в P3-031), а охотник не издаёт звука при ранении. Это главное событие боя (M005: «звук удара, комичный визг»).
- Нож без звука замаха и удара (`_strike("")`); у дубины нет замаха, только удар.
- Попадание стрелы/копья/камня в кабана звучит так же, как падение в землю (`arrow_fell`, `spear_fell`, `rock_fell`) — нет звука попадания в тушу.
- `net_fell` одинаков для земли и для накрытого кабана.
- Смерть кабана: звук просто обрывается (`silent = true`), предсмертного визга и падения туши нет.
- `no_ammo` — заглушка (отмечено в P3-050).
- Ветер (`cliff_sound`) только у обрыва лагеря; на карте охоты у скал и на вершинах ветра нет.

## 4. Порядок работ (задачи в BACKLOG)

1. **P3-081** Шины и ползунки громкости, `Sfx.play_ui`. Нужен для всего остального.
2. **P3-082** Бой: удар тараном и вскрик, попадание в тушу, смерть кабана, нож и дубина. Нужны записи.
3. **P3-083** Ловушки, сеть и приманки: срабатывание по видам, барахтанье, постройка, приманка.
4. **P3-084** Кабаны: удаляющийся топот при побеге, разгон тарана, сигнал редкого кабана, тон по виду, чавканье.
5. **P3-085** Езда: сесть, слезть, сброшен, таран верхом.
6. **P3-086** Тело охотника: падение, низкое здоровье, одышка, прыжок/приземление, рывок, глоток, подбор.
7. **P3-087** Лагерь и лавки: покупка, отказ, открытие лавок, рог начала охоты.
8. **P3-088** Интерфейс: +бивни, цель выполнена, итоги, кнопки, кольцевые меню.
9. **P3-089** Музыка: лагерь, охота слоями, стинг редкого кабана, джинглы итогов.
10. **P3-090** Фон: ветер на карте охоты, точечные птицы, насекомые, листва.

Для каждой задачи владелец даёт записи (папка на группу, 2+ дубля, как в P3-030); пока записей нет, задачу можно закрыть только по коду, если владелец разрешит временные заглушки.
